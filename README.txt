#===== This repository provides the experimental datasets for flow fields and oxygen concentration maps ==========
1) The Data given in these sub-repositories are used in the article titles, 'Unravelling three-dimensional active transport by ciliary arrays on coral surfaces', by Selvan and Cesar et al. (2026), submitted to PRX Life.
2) Exp_Flow_field_without_external_flow.mat: This data file containing the experimental flow field of the coral surface in the absence of external flow, as presented in Fig.~3(b) and (c).
3) Exp_Flow_field_with_external_flow.mat: This data file containing the experimental flow field of the coral surface in the presence of external flow, as presented in Fig.~5(b).
4) Exp_Oxygen_profile.mat: Data file containing the experimental oxygen profile of the coral surface in the presence of external flow, as presented in Fig.~7(b).
5) Exp_Velocity_profile_for_oxygen_profile.mat: This data file containing the experimental velocity profile (streamlines) of the coral surface in the presence of external flow, as presented in Fig.~7(b).
